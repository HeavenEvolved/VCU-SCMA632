Please ensure the filenames remain unchanged.

## *Source(s)*

This assignment utilizes two primary data sources:

1. **NSSO 68th Round Data (`NSSO68.csv`):** This dataset was collected by the National Sample Survey Office under the Ministry of Statistics and Programme Implementation in their 68th round of data collection. It provides insights into household consumption expenditures in India. It is used to analyze factors influencing food consumption patterns.

   * *Reference:* National Sample Survey Office, Ministry of Statistics and Programme Implementation, Government of India.

2. **Meghalaya GeoJSON:** This file contains the GeoJSON data for the state of Meghalaya in India. It contains the data to plot a map of the state with District divisions.

   * *References:* Data collected by GitHub user datta07 on their [INDIAN-SHAPEFILES](https://github.com/datta07/INDIAN-SHAPEFILES/tree/master) GitHub repository. The specific file can be found [here](https://github.com/datta07/INDIAN-SHAPEFILES/blob/master/STATES/MEGHALAYA/MEGHALAYA_DISTRICTS.geojson)
