* `IPL SALARIES 2024.xlsx`

Please ensure the filenames remain unchanged.

## *Source(s)*

This assignment utilizes two primary data sources:

1. **NSSO 68th Round Data (`NSSO68.csv`):** This dataset is derived from the National Sample Survey Office's 68th round, providing insights into household consumption expenditures in India. It is used to analyze factors influencing food consumption patterns.

   * *Reference:* National Sample Survey Office, Ministry of Statistics and Programme Implementation, Government of India.

2. **Indian Premier League (IPL) Data (`IPL_ball_by_ball_updated till 2024.csv`, `IPL SALARIES 2024.xlsx`):**

   * The `IPL_ball_by_ball_updated till 2024.csv` file contains comprehensive ball-by-ball match statistics for all IPL seasons up to 2024, including player actions, runs scored, and wicket events.

   * The `IPL SALARIES 2024.xlsx` file provides official player contract and compensation details for the 2024 IPL season.

   * *References:* Data compiled from various publicly available IPL statistics sources. For general IPL context and official information, you may refer to:

     * IPL Official Website: <https://www.iplt20.com>

     * ESPN Cricinfo: <https://www.espncricinfo.com/>
